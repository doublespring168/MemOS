## 2. Python加载与生效规则

多数BaseConfig strict=True/extra=forbid；Reader部分extra=allow、GeneralScheduler extra=ignore。ConfigFactory先校验backend再生成具体模型，运行Factory才建client。不存在“所有Pydantic自动读env”。

api/config导入时dotenv(override=True)，可覆盖已有环境；随后Nacos成功拉properties写env；watch只改env，不全面重建对象。其他模块dotenv通常不override，import时机决定配置快照。settings.MEMOS_DIR导入时取MEMOS_BASE_PATH/cwd，DEBUG固定False。

| 配置模块 | 主要作用/消费者 |
|---|---|
| mem_os/mem_cube | MOS开关、模型/Reader、四Memory槽、Cube schema和允许backend |
| memory | 文本/树/偏好/KV/LoRA/Feedback的嵌套配置 |
| llm/llm_rate_limit | provider生成参数、备份、按模型QPS规则 |
| embedder | 模型/维度/输入长度/多模态/备份 |
| graph_db/vec_db | 连接/租户/索引维度；后端覆盖不完全相同 |
| mem_reader/chunker/parser | 抽取职责模型、窗口、文件/多模态、切片 |
| reranker | backend+任意字典，由Factory解释具体键 |
| mem_scheduler | 执行队列/线程/Monitor/认证配置 |
| mem_user/mem_chat/mem_agent | 用户存储、独立聊天、检索Agent |
| internet_retriever | 联网服务，None可不构造 |
| prefer_text_memory/config | 独立偏好extract/add/retrieve三段 |

### 2.1 需要明确的约束

- GeneralMemCube槽允许列表比MemoryFactory更窄；Simple类构造要求注入；LoRA仍占位。
- API MOS_EMBEDDER_BACKEND只特判universal_api，否则走ollama；Factory本身还支持ark/sentence_transformer。
- API MOS_RERANKER_BACKEND只保留http_bge/http_bge_strategy，否则cosine；env noop不等于Noop实例。
- MEMRADER_*拼写是源码实际名称；主抽取、general、image、document、preference、feedback、suggestion、scheduler、chat模型职责不同。document无general时可为None，文件chunk回退不等于必用主LLM。
- GRAPH_DB_BACKEND优先旧NEO4J_BACKEND；共享库user_name、community多库/auto_create限制需满足。
- EMBEDDING_DIMENSION在多路径使用且缺省不同；某些PolarDB SQL固定1024，修改字段不自动改变全部存储实现。
- 部分布尔env精确比较小写true，部分lower或支持1/on；不能套统一解析规则。
- Scheduler db_path/db_url/enable_orm_persistence/enhance_*字段未找到运行消费，API明确传临时SQLite；不能按description宣称其控制当前ORM。
- LLM limiter只允许ENABLED/RULES两env，其他同前缀变量报错；显式配置覆盖env、只匹配列出的model，默认关闭。
- 普通凭证字段多为str，BaseConfig导出仍可能包含；Nacos日志掩码不是全局SecretStr。

证据：[APIConfig](../src/memos/api/config.py)、[builders](../src/memos/api/handlers/config_builders.py)、[BaseConfig](../src/memos/configs/base.py)、[rate config](../src/memos/configs/llm_rate_limit.py)。

## 4. v2运行配置

实际优先级：MEMOS_HOME→MEMOS_CONFIG_FILE父目录→adapter defaultHome→agent默认；缺YAML用DEFAULT_CONFIG。用户结构prune未知字段→deepMerge默认→TypeBox Value.Default/校验。下面默认以DEFAULT_CONFIG为先；可选schema字段没有该默认时保留schema表达式，不擅自补值。

| 分组 | 作用与实际生效 |
|---|---|
| viewer/bridge | Viewer绑定；OpenClaw/Hermes端口固定18799/18800；bridge mode/port/openOnFirstTurn未找到运行读取 |
| embedding | 本地/远端向量、缓存与分块；新默认maxInputTokens1024，旧配置兼容0 |
| llm | 主处理模型；可fallbackToHost |
| skillEvolver/l3Llm | 分别L2+技能与L3专用，provider/model不全则回主LLM |
| storage | FTS tokenizer |
| algorithm | lightweight默认true；capture/reward/L2/L3/skill/feedback/session/retrieval各阶段参数 |
| hub | client/hub共享，默认关闭，端口18912 |
| telemetry/logging | 遥测、level/channel/轮转/内容与secret掩码 |

writer保留YAML注释并临时写/rename，权限0600；磁盘并非加密。GET/PATCH六secret字段mask；空字符串/遮蔽标记保留旧秘密。只这些字段允许受限${ENV_NAME}规则。配置保存不全热更新：模型/algorithm启动构建，Hub可即时重启；GET/health读盘新标签不证明client已更换。

证据：[defaults](../apps/memos-local-plugin/core/config/defaults.ts)、[schema](../apps/memos-local-plugin/core/config/schema.ts)、[resolver](../apps/memos-local-plugin/core/config/index.ts)、[writer](../apps/memos-local-plugin/core/config/writer.ts)。
