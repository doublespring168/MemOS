# MemOS 后端接口列表

> 2026-10-02；提交 `a7367d07`。以当前源码注册/分发为准，按功能分组。URL 是相对各服务 base URL 的路径；`{id}` 与 `:id` 表示参数。本文列服务端接口，不把云 SDK 的外部请求路径当成本地实现。MCP/JSON-RPC/IPC 没有“一方法一 URL”，以协议名列出。静态解析不意味着接口已通过运行验证。

## 1. 服务与挂载范围

| 服务 | Base/范围 | 开启条件 |
|---|---|---|
| Python 基础 API | `/product/*`、`/health`、`/download/*`、框架文档 | server_api:app；模块导入阶段初始化组件 |
| Python 扩展 API | 基础产品路由 + `/admin/*` | server_api_ext:app；安全/限流配置 |
| Dream | `/dream/*` | 插件安装/启用且 init_app 挂载；基础 app 有该生命周期调用，扩展 app 当前未执行同一步 |
| v2 Viewer HTTP | `/api/v1/*` | Adapter/Bridge 启动服务，常见18799/18800/18801 |
| v2 Hub | `/api/v1/hub/*` | hub.enabled 且 hub role，独立端口通常18912 |
| v1 Viewer/Hub | `/api/*` / `/api/v1/hub/*` | OpenClaw 插件的本地服务，端口与v2部分重叠 |
| Cloud 配置 UI | `/api/state` 等 | 独立 loopback 配置 UI；不是云 API 本体 |
| OpenWork | IPC + 权限/浏览器本地 HTTP | Electron main 与 MCP 工具子服务 |

### 调用约束

新增/检索重点参数在 [product_models.py](../src/memos/api/product_models.py)：user_id、readable_cube_ids/writable_cube_ids、messages、filter、mode、memory_limit_number 等。请求模型不等于 env 配置。直接标量参数（如 scheduler/wait 的 user_name、Dream trigger 的 cube_id）按 FastAPI 函数声明通常从 query 提取，不能默认将其作为 JSON body。

`/product` 当前未声明 verify_api_key/scope 依赖，不能因 auth.py 存在就认定全部路由已鉴权。扩展 `/admin` 密钥操作明确接入依赖。请求错误、后端接口支持程度和流式结束条件需分别核对 Handler。

框架/静态接口：基础 FastAPI 默认还提供 `GET /docs`、`GET /redoc`、`GET /openapi.json` 和 Swagger OAuth redirect；`/download/{path}` 是 StaticFiles 文件挂载，不是业务 API。静态目录须存在。它们不计入34项业务注册统计。

## 9. 列表核对口径

Python通过AST提取路由装饰器并拼APIRouter prefix，v2取实际Routes注册，原生服务取if/正则分发并保留method未限制边界。动态插件可以在安装后添加其他路由；本文列当前仓库实现，不能穷举外部插件。根packages/memos-core重复v1式接口但未作为现有apps共享服务挂载，不重复计服务实例。

接口覆盖率和测试证据见 [7-测试用例.md](7-测试用例.md)；本文不据OpenAPI旧快照推断接口已存在或测试成功。
