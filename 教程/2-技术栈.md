# MemOS 前后端核心技术栈

> 分析日期：2026-10-02；源码提交：`a7367d07`。基于全仓源码索引、实际 import/调用、各 package.json、pyproject、构建与部署文件整理。版本均为当前仓库声明范围，不代表最新版本或当前机器安装版本。本文是静态分析，没有启动模型、数据库或完整应用。模块关系详见 [1-模块关系.md](1-模块关系.md)。

## 1. 技术栈总览

仓库包含多套应用，前后端并非只有一组 React + Python 服务。

| 子系统 | 前端 | 后端/运行时 | 存储与通信 |
|---|---|---|---|
| Python MemoryOS | 无专属生产前端；FastAPI 自带 API 文档 | Python、FastAPI、Pydantic v2、线程调度、模型 SDK | SQLAlchemy 用户/状态，图/向量后端，Redis/RabbitMQ；REST/SSE/MCP |
| 本地插件 v2 | Preact、Signals、TypeScript、Vite、原生 CSS | Node.js、TypeScript、自实现 HTTP Router、MemoryCore 事件管道 | better-sqlite3、FTS5、自实现余弦检索；HTTP/SSE、JSON-RPC |
| 本地 OpenClaw v1 | 服务端返回的内嵌 HTML/CSS/JS | Node.js、TypeScript、原生 HTTP、采集/入库/召回 | better-sqlite3、FTS/向量/LIKE；HTTP 与宿主 Hook |
| Cloud OpenClaw 插件 | 原生 HTML/CSS/JS 配置 UI | JavaScript ESM、Node.js、宿主 Hook、fetch | 云记忆 HTTP API，本地配置文件 |
| OpenWork 集成 | React、React Router、Zustand、Tailwind/Radix | Electron 主进程、Node.js、OpenCode CLI/PTY | electron-store、preload IPC、云 MemOS HTTP、工具 MCP |

## 3. Python 后端技术

### 3.1 服务、类型、配置和进程

| 技术 | 主要功能与当前用途 | 声明/源码 |
|---|---|---|
| Python | 库、CLI、API、任务与 provider 实现 | pyproject `>=3.10`；Poetry Python 范围 `>=3.10,<4.0` |
| FastAPI | REST 路由、依赖、异常、lifespan、OpenAPI | 核心 `>=0.115.12,<0.116.0`；[server_api](../src/memos/api/server_api.py) |
| Starlette | ASGI 组件、StaticFiles、middleware、StreamingResponse | 由相关依赖提供；服务下载目录/SSE |
| Uvicorn | 运行 ASGI App | Makefile serve、Docker CMD；不是业务框架 |
| Gunicorn | 多 worker 进程管理 | Krolik Docker CMD + Uvicorn worker；当前部署模板需额外核对可用性 |
| Pydantic v2 | 校验/序列化、validator、模型字段 | 配置、MemoryItem、API、Scheduler schema；[BaseConfig](../src/memos/configs/base.py) |
| PyYAML/python-dotenv | YAML 文件和环境配置 | BaseConfig、API、日志、技能存储；不是密钥管理服务 |
| requests/HTTP clients | 同步出站 HTTP | 云 SDK、Nacos、BGE reranker、联网和可选日志发送 |
| ContextVar/线程/线程池/asyncio | 请求隔离和并行执行 | ContextThread 显式复制上下文；Reader/Search/Feedback/Scheduler 并发、聊天后处理 |

当前混合同步 SDK、线程池和 async handler，不是全程异步 I/O。Pydantic/Starlette/Uvicorn/requests/PyYAML 等未都作为 pyproject 直接核心依赖单独声明，部分由传递依赖或部署 requirements 提供。

### 3.2 存储技术

| 技术 | 功能与项目用途 | 声明/实现证据 |
|---|---|---|
| SQLAlchemy 2 | ORM/事务/连接管理 | 核心 `>=2.0.41,<3.0.0`；[UserManager](../src/memos/mem_user/user_manager.py)、Scheduler ORM |
| SQLite | 本地用户/Cube 和 Monitor 状态 | SQLAlchemy engine；Scheduler 默认 helper 实际创建临时数据库 |
| MySQL/PyMySQL | 用户及配置/可选调度 ORM | PyMySQL `>=1.1.0,<2.0.0` 在核心且重复列 extras |
| PostgreSQL/psycopg2 | 直接 SQL、JSONB 节点/边、连接池 | [postgres.py](../src/memos/graph_dbs/postgres.py)；pyproject 未直接声明 psycopg2，但 docker requirements 有 |
| pgvector | vector 列、索引、余弦距离算子 | Postgres memories 与 `<=>`；是数据库扩展，非 Python 模型库 |
| PolarDB/Apache AGE | SQL + Cypher 图存储 | [polardb.py](../src/memos/graph_dbs/polardb.py)；图/全文/向量、连接池 |
| Neo4j | 节点/关系/子图/原生向量 | Python driver `>=5.28.1,<6.0.0`；tree-mem/all |
| Neo4j Community + VecDB | 图与向量组合存储 | 正文/边 Neo4j，向量交 Qdrant/Milvus 等；[community](../src/memos/graph_dbs/neo4j_community.py) |
| Qdrant | 向量与 payload CRUD/过滤 | qdrant-client all `>=1.16.0,<2.0.0`；本地或远端 |
| Milvus | dense/sparse/BM25/hybrid、collection | pymilvus pref-mem `>=2.5.12`，all `>=2.6.1`，均 `<3.0.0` |
| Redis | Streams、Hash/Set 状态、锁、历史、出站 QPS | redis-py mem-scheduler/all `>=6.2.0,<7.0.0` |
| RabbitMQ/Pika | AMQP 事件发布/消费 | pika `>=1.3.2,<2.0.0`；主要用于 Scheduler Web/MemoryChange 事件 |

这些 backend 按配置选择，不是每次启动都同时使用全部。数据库 driver 的版本不是数据库服务器版本。Neo4j fulltext 和部分通用图操作存在占位，存储注册不代表所有算法场景可无差别替换。

### 3.4 检索、重排、缓存与重试

| 技术/算法 | 主要功能 | 本项目使用边界 |
|---|---|---|
| jieba | 中文分词/关键词 | 检索 tokenizer、网页 tags、反馈关键词 |
| rank-bm25/BM25 | 基于词项的相关性 | 树记忆召回；Milvus BM25 则由数据库 sparse function 执行 |
| scikit-learn TF-IDF/余弦 | 词项向量、文本相似 | Scheduler 去重、可选 BM25 融合、本地重排；核心 `>=1.7.0,<2.0.0` |
| MiniBatchKMeans/NumPy | embedding 聚类、数值计算 | 树重组聚类后交 LLM 摘要，不是训练 LLM |
| HTTP BGE reranker | query/document 相关性评分 | requests 调远端服务，本地组合 sources/background |
| datasketch MinHash/LSH | 近似 Jaccard 去重 | 偏好工具函数存在，但主 src 未找到调用，非默认写入必经 |
| cachetools TTL/LRU | 内存缓存 | 精确文本 embedding 缓存、trace 缓存、BM25 语料；核心 `>=6.0.0` |
| Future singleflight | 合并并发相同请求 | embedding 并发请求复用；不同于近似语义去重 |
| WeakValueDictionary 工厂复用 | 同配置对象复用 | LLM/Reader/Embedder 等实例，区别于结果缓存 |
| Tenacity | 可配置重试 | JSON 抽取解析、反馈 embedding/DB；核心 `>=9.1.2,<10.0.0` |
| Redis Lua/GCRA | 原子 QPS/burst admission | 出站 LLM model quota、本地等待/超时/队列容量；非 Tenacity 实现 |
| schedule | 周期调用 | 树重组器线程周期优化；与 Redis 任务调度是不同机制 |

## 6. 核对结论与阅读建议

先按所使用的子系统学习：Python 服务看 FastAPI/Pydantic→Reader/模型→存储→Scheduler；v2 看 Preact/Signals→HTTP/MemoryCore→SQLite/检索→可选进化；OpenWork 看 React/Zustand→IPC→OpenCode/云 HTTP。技术清单应结合执行开关、真实 import 和构建入口阅读，不能仅依据 lockfile 中的传递包认定项目采用相应框架。
